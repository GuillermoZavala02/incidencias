# Proyecto de plataforma para manejo de incidencias.
plataforma para el manejo de incidencias entre usuarios inspirada en jira

# objetivo
El proyecto nace con la idea de practicar fundamentos de desarrollo backend con Java y Spring Boot
desde la definicion de requerimientos, reglas de negocio, diseño de la base de datos, creacion de endpoints,
patrones de diseño, etc. Ademas de practicar desarrollo con agentes, delegando el desarrollo del frontend.

# Funciones
-Login/Registro.
-Creación y asignación de incidencias.
-Seguimiento de incidencias.
-Control de cambios
-Roles y permisos.

# Tecnologias

- Java
- Spring Boot
- PostgreSQL
- Maven

# Arquitectura
El proyecto sigue una arquitectura en capas con las siguientes capas:
- Entidades
- Repositorios
- Servicios
- Controladores
- Excepciones
- Utilidades

# Estado del proyecto

Actualmente se encuentra en fase de desarrollo, se tiene un esqueleto del proyecto con las entidades basicas
y servicios, faltan endpoints, validaciones, etc.
